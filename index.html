### Core Architecture & Features

Memory Management

4‑level paging memory isolation mapped successfully at high canonical addresses.

Multitasking

Cooperative multitasking powered by a custom asynchronous task executor.

Storage & Drivers

Low‑level PIO ATA driver implementation and a custom FAT‑like filesystem parsing sectors directly from LBA 0.

Bare‑Metal Compatibility

Tested and verified on physical x86_64 hardware architectures.
